## Mozilla PDF.js (Apache-2.0)

The PDF rendering engine is vendored into the JavaScript bundle by
`mobile/scripts/gen-pdfjs.js` from the pinned `pdfjs-dist` dependency so that PDF
reading works with no network access. The generator preserves the Apache-2.0
license header at the top of each generated source file, and those headers ship
inside the application bundle. `npm run check:pdfjs` verifies the generated
output against the installed package.

## Bundled data assets

### `mobile/assets/dictionary.json` — offline dictionary (20,000 headwords)

* Provenance: the definition text is derived from *Webster's Revised Unabridged
  Dictionary* (G. & C. Merriam, 1913), a work in the public domain in the United
  States. Entries are truncated to a bounded length and reformatted as JSON for
  on-device lookup; `partOfSpeech` labels are normalized.
* License: public domain in the United States. Redistribution is permitted.
  Public-domain status is jurisdiction-specific; distributors outside the United
  States are responsible for their own local review.
* No network service, remote font, or online dictionary is contacted at runtime.

### Fonts

No third-party font file is bundled in the release APK. Reader typography uses
system fonts by default. Fonts installed or imported by the user at runtime
(`FontService`) are the user's own files and are not redistributed by Lirune.

## Test-only material

The QA corpus (`Lirune-Android-RealFile-QA/`), Maestro flows, screenshots, and
unit-test fixtures are development material. Sample book files are generated by
the tracked generator scripts, are gitignored, and are not packaged into the
release APK.

## Not bundled

`epubjs`, Electron, and `electron-builder` are **not** dependencies of the Android
application. They appear only in the repository-root notice for the legacy
Windows shell. Nothing in this file grants or implies a license for them in the
Android distribution.
