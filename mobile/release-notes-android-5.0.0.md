# Lirune Reader v5.0.0 — Major Mobile Release: In-Reader Theme Parity & High-Performance Engine

Lirune v5.0.0 is the major generation milestone for Android, bringing deep in-reader theme parity, full Hermes bytecode optimization, and robust multi-format support without compromising privacy.

### Highlights
- **In-Reader Theme Parity**: Settings sheet, Table of Contents sheet, Annotations sheet, Search sheet, and Dictionary modals dynamically inherit colors, surfaces, borders, and typography from the active reader palette across all 15 themes.
- **Modern Dark Theme Support**: Added proper dark-surface token mapping for Nord, Gruvbox, Solarized, Rosé Pine, Dracula, and Mocha; corrected classification for Soft Forest.
- **Hermes Bytecode Engine**: Pre-compiled 1,583 JavaScript modules for instant reader launch and fluid 60fps scrolling.
- **Zero Internet Permissions**: `android.permission.INTERNET` permanently stripped from release builds. Zero tracking, zero telemetry.
- **Universal Multi-Format Compatibility**: Native readers for EPUB, PDF, MOBI, CBZ, CBR, CBT, FB2, TXT, MD, DOCX, DOC, ODT, RTF, TIFF, DJVU, and images.
- **412 Automated Tests Passed**: Complete test coverage across navigation, layout, security, and storage layers.
